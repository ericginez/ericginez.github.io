# Parcours

Chronologie de la formation et des projets réalisés.

## Formation Data Engineer

Formation suivie à distance avec OpenClassrooms du **3 novembre 2025 au
3 août 2026**.

Le parcours représente :

- **603 heures de formation guidée** ;
- **603 heures de projets supervisés** ;
- **13 projets professionnalisants** ;
- un rythme de travail pouvant atteindre **35 heures par semaine**.

## Progression du parcours

### Fondamentaux de la donnée

Les premiers projets ont permis de développer les bases de l’analyse de
données, de la modélisation et des bases relationnelles :

- analyse exploratoire avec Python et Pandas ;
- conception de bases SQL ;
- audit d’environnements de données ;
- formalisation des besoins et des flux.

### Stockage, qualité et machine learning

La suite du parcours a approfondi les méthodes de stockage et
d’exploitation des données :

- migration vers MongoDB ;
- sécurisation et validation des données ;
- préparation de données pour le machine learning ;
- entraînement, évaluation et exposition de modèles ;
- création de restitutions avec Power BI.

### Infrastructure et cloud

Plusieurs projets ont porté sur l’industrialisation des traitements :

- ingestion automatisée ;
- conteneurisation avec Docker ;
- orchestration avec Kestra ;
- architectures AWS ;
- bases PostgreSQL managées ;
- pipelines reproductibles et observables.

### Streaming et traitement distribué

Le parcours a également couvert les architectures événementielles :

- Redpanda et Kafka API ;
- Spark Structured Streaming ;
- traitements continus ;
- stockage JSON et Parquet ;
- architectures locales, hybrides et cloud.

### Intelligence artificielle et RAG

Un système de recommandation d’événements culturels a été conçu avec :

- OpenAgenda ;
- LangChain ;
- Mistral ;
- FAISS ;
- embeddings et recherche sémantique ;
- évaluation fonctionnelle sur un jeu de questions de référence.

### Industrialisation et pilotage

Les derniers projets ont permis de consolider les compétences de Data
Engineer :

- architecture ELT Bronze–Silver–Gold ;
- traitements historiques et incrémentaux ;
- orchestration, tests et reporting Power BI ;
- passage d’un système RAG du POC au MVP ;
- conception d’une architecture cloud scalable ;
- planification, estimation des coûts et gestion des risques ;
- réalisation et publication du portfolio professionnel.

## Objectif professionnel

Mettre en œuvre des architectures de données fiables, automatisées et
évolutives, depuis l’ingestion des sources jusqu’à leur exploitation
analytique, tout en garantissant la qualité, la traçabilité, la sécurité et
la maîtrise des coûts.
